
# Twitter Sentiment Analysis

A Machine Learning project that classifies tweets as **Positive or Negative** using Natural Language Processing (NLP).

## Features
- Text preprocessing and cleaning
- TF-IDF feature extraction
- ML models: Logistic Regression, Naive Bayes, and Linear SVM
- Sentiment prediction for individual tweets
- Bulk sentiment analysis using CSV files
- Interactive Streamlit interface

## Tech Stack
Python, Pandas, Scikit-learn, NLTK, TF-IDF, Streamlit

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Dataset
10,000 tweets with positive and negative sentiment labels.
